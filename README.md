### Quick Start

Install dependencies:

```bash
yarn install
```

Run development mode:

```bash
yarn dev
```

Build project:

```bash
yarn build
```


> [!IMPORTANT]
> **Experimental Project**
>
> Jangan gunakan akun WhatsApp utama untuk testing.
>
> VisionCane Core menggunakan library pihak ketiga yang berinteraksi dengan WhatsApp Web. Library tersebut **tidak berafiliasi, didukung, atau secara resmi terhubung dengan WhatsApp maupun Meta**.
>
> "WhatsApp" dan seluruh merek terkait merupakan hak milik pemegang masing-masing.
>
> Penggunaan project ini menjadi tanggung jawab pengguna. Maintainer tidak mendukung:
>
> - Spam messaging
> - Bulk messaging
> - Penyalahgunaan otomatisasi
> - Stalkerware
> - Aktivitas yang melanggar Terms of Service WhatsApp
>
> Gunakan secara bijak untuk pengembangan, riset, dan eksperimen.
